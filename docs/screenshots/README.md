# DevInspect AI Screenshot Gallery

This directory houses the product screenshots showcased in the main `README.md`.

## Expected Screenshots
For a complete public v1.0.0 presentation, ensure the following files exist in this folder:

1. **`dashboard_overview.png`**: The landing view displaying the CRT overlay, animated prompt input, and configuration buttons.
2. **`repository_analysis.png`**: The main scorecard dashboard showing the circular score gauge and deterministic results breakdown.
3. **`documentation_analysis.png`**: The README metrics analyzer highlighting checklist items and power level bars.
4. **`persona_reviews.png`**: The 5-persona reviewer panel showcasing the tabs (Senior Engineer, Recruiter, DevOps, Maintainer, CTO).
5. **`security_scanner.png`**: The Diagnostics Board showing flagged credentials alerts and file exposures.
6. **`export_reports.png`**: The print-mode selection modal showing downloadable document configurations.
7. **`recruiter_view.png`**: Recruiter-specific report card mockup ready to export.
8. **`cto_view.png`**: CTO-specific technical roadmap and risk scorecard mockups.

## Screenshot Capture Guidelines
- **Theme**: Keep the dark neon/JetBrains theme active.
- **Vignette**: Ensure the CRT overlay is subtly visible.
- **Sizing**: Maintain standard HD resolution (e.g. 1920x1080 or 1280x720) with a 16:9 ratio.
